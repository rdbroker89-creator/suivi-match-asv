COACH RÉMY ASV - V11 TER

NOUVEAU SUR LES BUTS
- Chaque but Villeroy possède un bouton ✏️ dans le fil du match.
- Tu peux modifier le buteur.
- Tu peux modifier, ajouter ou retirer le passeur décisif.
- Tu peux annuler complètement un but pour hors-jeu ou erreur.
- Lorsqu'un but est annulé :
  * le score Villeroy est recalculé automatiquement ;
  * les statistiques buteurs/passeurs sont recalculées ;
  * une ligne "But annulé" reste dans le fil pour garder une trace ;
  * le résumé final mentionne les buts annulés.

Toutes les fonctions V11 bis sont conservées :
- chrono persistant en arrière-plan
- 4 remplaçants vides à la préparation
- listes sans doublon
- historique local des matchs
- repositionnements tactiques silencieux
- correction NaN
- export JSON
- résumé ChatGPT
