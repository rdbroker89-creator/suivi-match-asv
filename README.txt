CORRECTIONS IMPORTANTES
- Nouveau cache v3 : évite de rester bloqué sur l'ancienne version.

- Les anciens caches sont supprimés automatiquement.
- L'écran "Préparer le match" est forcé pour tout nouvel état.

INSTALLATION / MISE À JOUR GITHUB PAGES
1. Remplacer index.html, manifest.webmanifest, sw.js, README.txt et le logo dans le dépôt.
2. Commit changes.
3. Attendre le déploiement GitHub Pages.
4. Sur iPhone, supprimer l'ancienne icône de l'écran d'accueil.
5. Ouvrir l'URL GitHub Pages dans Safari et actualiser.
6. Vérifier que "Version 3.0" et "Préparer le match" apparaissent.
7. Ajouter ensuite à nouveau à l'écran d'accueil.
