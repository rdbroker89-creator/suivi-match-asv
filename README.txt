AS VILLEROY - Suivi Match PWA v7

NOUVEAUTÉS
- Page "Préparer le match" entièrement revue.
- Équipes du Groupe B préchargées :
  GÂTINAIS 1, MONÉTEAU, LINDRY, BLÉNEAU, BEINES,
  MAILLY-LA-VILLE, ST-CLÉMENT, APPOIGNY 2, ROSOY.
- Option AUTRE / AMICAL avec saisie libre.
- Domicile / extérieur.
- Sens du score automatique selon domicile / extérieur.
- Date, heure et lieu.
- Lieu automatiquement proposé puis modifiable.
- Formations : 3-2-1, 2-3-1, 2-2-2, 3-1-2, 1-3-2, 1-2-3, personnalisée.
- Mentalité : défensive, équilibrée, offensive.
- Aperçu tactique déplaçable au doigt avant le match.
- Placement live déplaçable pendant le match.
- Un remplaçant reprend automatiquement la position du joueur remplacé.
- Une permutation échange les positions visuelles.
- Les repositionnements live sont mémorisés.
- Bouton "Dupliquer le dernier match".
- Bouton "Envoyer le résumé à ChatGPT".
- Bouton "Copier le résumé".
- Résumé avec score dans le bon sens domicile / extérieur pour aider à créer l'affiche finale.

FONCTIONS CONSERVÉES
- Chrono 2 x 40 minutes.
- Reprise de la 2e mi-temps à 40:00.
- Temps additionnel 40+1, 40+2...
- Buteurs et passeurs.
- CSC.
- Changements et permutations.
- Sauvegarde à chaque action.
- Point de sauvegarde toutes les 5 minutes.
- Sauvegarde de sécurité du chrono toutes les 10 secondes.
- Sauvegarde lors du passage en arrière-plan.
- Export JSON.
- Fonctionnement hors ligne après installation.

MISE À JOUR GITHUB
1. Décompresser ASV_Suivi_Match_App_v7.zip.
2. Remplacer les fichiers du dépôt GitHub par ceux du ZIP.
3. Cliquer sur Commit changes.
4. Attendre le déploiement GitHub Pages.
5. Ouvrir le site dans Safari et vérifier "Version 7.0".
6. Si une ancienne version reste affichée, supprimer l'ancienne icône de l'écran d'accueil,
   ouvrir le site dans Safari avec ?v=7 puis l'ajouter à nouveau à l'écran d'accueil.

IMPORTANT
Le bouton "Envoyer le résumé à ChatGPT" utilise la feuille de partage iOS.
Si l'app ChatGPT est proposée dans la feuille de partage, sélectionne-la.
Sinon le résumé est copié et peut être collé dans ChatGPT.
